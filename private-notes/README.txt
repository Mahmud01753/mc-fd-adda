---- আপডেট (২০২৬-১০-২৩, ৪): রেফারার লিংক + Restriction + ব্যান নোটিশ ----
নতুন SQL (Supabase SQL Editor-এ একবার করে Run; না চালালে সাইট আগের মতোই চলে, নতুন অংশ কাজ করবে না):
  1) supabase-ref-log.sql  — কে কোন লিংক থেকে ঢুকেছে তার আগের পুরো লিংক। একই ব্যক্তির একই লিংক একবারই থাকে (শুধু কতবার/শেষ কখন বাড়ে)।
     দেখতে: অ্যাডমিন → 💬 চ্যাট ইউজার → ইউজারের "📋 সব তথ্য" → "🔗 আগের লিংক"। (খোঁজার ঘরেও লিংক দিয়ে খোঁজা যায়।)
     ⚠ ফেসবুক/ব্রাউজার অনেক সময় রেফারারে শুধু ডোমেইন পাঠায় বা কিছুই পাঠায় না — সেটা সাইট থেকে বদলানো যায় না। যা আসে পুরোটাই রাখা হয়।
  2) supabase-restrict.sql — ⚠️ Restriction সিস্টেম (কাস্টম সময় ১ মিনিট – ৩৬৫ দিন)।
Restriction (ওয়ার্নিং-চিহ্ন) — ইউজার চ্যাট করতে পারে, কিন্তু:
  * ছবির কোনায় ❌; বার্তা লাল ডোরাকাটা ড্যাশ-বর্ডার বাবলে + "⛔ RESTRICTED" ট্যাগ + নামের পাশে "Restricted" পিল।
  * ❌ / ট্যাগ / পিলে চাপলে সবাই তাকে দেওয়া ওয়ার্নিং, দেওয়ার সময় ও মেয়াদ দেখে।
  * সে নিজে চ্যাটের ওপরে সবসময় নিজের ওয়ার্নিং (বাকি সময়সহ) দেখে। মেয়াদ শেষে নিজে চলে যায়।
  * অ্যাডমিন: মডারেশন → 🟢 সক্রিয় ইউজার / 👥 Review তালিকা / 🚩 রিপোর্ট থেকে "⚠️ Restriction" → ওয়ার্নিং লিখুন + সময় (প্রিসেট বা ✏️ কাস্টম)।
    ⚠️ Restriction তালিকা ট্যাবে চলমান/ইতিহাস; একটা বা সব ওয়ার্নিং তোলা ও আরেকটি যোগ করা যায়।
ব্যান: আগের সার্ভার-সিস্টেমেই (বার্তা পাঠানো বন্ধ)। কাস্টম সময় ড্রপডাউনের "✏️ কাস্টম সময়…" থেকে (মিনিট/ঘণ্টা/দিন/সপ্তাহ; ৫ মিনিট – ৩০ দিন)।
  * ব্যান করা ইউজার চ্যাটে ঢুকলে ভেসে ওঠে: "আপনাকে ব্লক করা হয়েছে" + ওয়ার্নিং + বাকি সময়; চ্যাট দেখতে পারে, কিন্তু বার্তা/রিপ্লাই/ফাইল/রিঅ্যাকশন বন্ধ। নিচে লাল বারে ওয়ার্নিং থাকে।

supabase-restrict.sql আবার Run করুন (আগে চালালেও ক্ষতি নেই) — এতে যোগ হয়েছে: স্থায়ী লক, স্ক্রীনশট সেটিং, খারাপ-শব্দ পড়ার ফাংশন।
* 🔒 স্থায়ী লক: রিপোর্ট ছাড়াই অ্যাডমিন সরাসরি (সক্রিয় ইউজার / Review / রিপোর্টের পাশে "🔒 স্থায়ী লক")। খুলতে "🔓 লক খুলুন" বা মডারেশন → 🔒 লক ও স্ক্রীনশট।
* 🛡 স্ক্রীনশট সুরক্ষা: মডারেশন → 🔒 লক ও স্ক্রীনশট → ডিফল্ট বন্ধ; চালু করলে কয়েক সেকেন্ডে সবার চ্যাটে। ⚠ ফোনের পাওয়ার+ভলিউম স্ক্রীনশট ওয়েব থেকে আটকানো যায় না — এটা বাধা + ওয়াটারমার্ক।
* Restricted ইউজার: সাধারণ লেখা সবাই পড়ে (ছবিতে ❌ + RESTRICTED সাইন); লেখায় 🚫 খারাপ শব্দ ট্যাবের কোনো শব্দ থাকলে লেখা লুকিয়ে লাল বক্স। শব্দ মেলানো শুধু দেখানোর সময়; পাঠানো আটকায় না।


---- Restriction v2 (২০২৬-১০-২৩) ----
নতুন SQL: supabase-restrict-v2.sql — চালানোর ক্রম: (আগের মূল SQL সব) → supabase-restrict.sql → supabase-restrict-v2.sql (Supabase → SQL Editor, একবার; আবার চালালেও ক্ষতি নেই)।
১) ⛔ আইকনে (নামের পাশে/ছবির কোনায়/বাবলের "RESTRICTED" ট্যাগ) সবাই চাপলে পপআপ: কারণ, বাকি সময়, কে দিয়েছে (🤖 অটো / 👮 অ্যাডমিন)।
২) খারাপ শব্দ লিখলে সার্ভার (ট্রিগার) নিজেই অটো-Restriction দেয়: ১ ঘণ্টা → ২ → ৪ → ৮ … প্রতিবার দ্বিগুণ (সর্বোচ্চ ৩৬৫ দিন)। ৬০ সেকেন্ডের মধ্যে পরপর হলে নতুন ধাপ নয়। বার্তার লেখা সবার কাছে লুকিয়ে "কমিউনিটি ওয়ার্নিং" দেখায়।
৩) অ্যাডমিন → 🛡️ মডারেশন → ⚠️ Restriction তালিকা: চলমানের পাশে ⏱ সময় কমাও / ⏱ সময় বাড়াও / 🔓 বন্ধ করো; নিচে অ্যাকশন লগ। ইউজারের ইতিহাস পেইজেও লগ আছে। অটো-শাস্তি বন্ধ করার সময় "আগে বন্ধ করলে অটো-শাস্তি দ্বিগুণ-গণনায় ধরা হয় না।
৪) অ্যাডমিন একই ব্রাউজারে admin.html-এ লগইন থাকলে চ্যাটে যেকোনো বার্তায় চাপ দিলে মেনুতে "🛡️ অ্যাডমিন" বোতাম আসে: Restriction / সতর্ক / ব্যান / বার্তা সরান / চলমান Restriction-এর সময় বদল-বন্ধ। (লগইনের একটা কপি localStorage "mc2_adm_x"-এ থাকে; লগআউটে মুছে যায়।)
৫) ⛔ চাপলে সবাই কারণ/বাকি সময়/কে দিয়েছে দেখে; আসল আপত্তিকর মেসেজ সবার কাছে লুকানো বক্সে থাকে।
৬) অ্যাডমিন → 🛡️ মডারেশন → ⚠️ Restriction তালিকার ওপরে "Restriction সিস্টেম" চালু/বন্ধ বোতাম। বন্ধ থাকলে অটো-Restriction হয় না, নতুন দেওয়া যায় না, চ্যাটে কিছু দেখায় না। (supabase-restrict-v2.sql আবার চালাতে হবে)
৭) supabase-restrict-v3.sql (v2-এর পরে): অ্যাডমিন → ⚠️ Restriction তালিকায় "ওয়ার্নিংয়ের কারণ কারা দেখবে" — 🌐 সবাই / 🔒 শুধু ইউজার নিজে ও অ্যাডমিন। আসল আপত্তিকর মেসেজ দুই ক্ষেত্রেই সবার কাছে লুকানো। চালানোর ক্রম: মূল SQL → supabase-restrict.sql → v2 → v3।


---- আপডেট (২০২৬-১০-২৩, ৬): মেয়াদি লক + লক এখন ব্যান ট্যাবে ----
নতুন SQL: supabase-lock-timed.sql — সবার শেষে চালান (মূল SQL → restrict → v2 → v3 → lock-timed)। একবার Run; আবার চালালেও ক্ষতি নেই।
⚠ পরে restrict / v2 / v3 আবার চালালে lock-timed আবার সবার শেষে চালাতে হবে।
* 🔒 লক এখন স্থায়ী অথবা কাস্টম সময় (১ মিনিট – ৩৬৫ দিন; প্রিসেট বা ✏️ কাস্টম)। মেয়াদ শেষে নিজে থেকে খুলে যায় (সার্ভার সময় মেলায়)।
* লকের তালিকা এখন 👥 Review/ব্যান/লক তালিকা ট্যাবের ওপরে: বাকি সময়, 🔓 লক খুলুন, ⏱ মেয়াদ/কারণ বদলান। "🛡 স্ক্রীনশট সুরক্ষা" ট্যাবে শুধু স্ক্রীনশট সেটিং।
* চ্যাটে লকড ইউজার ব্যানের মতোই নোটিশ + বাকি সময় দেখে; মেয়াদ শেষে বার্তা পাঠানো নিজে থেকে চালু হয়।
* ঢোকার কোড: একবার সঠিক কোড দিলে সেই ডিভাইসে (localStorage "fa_unlock") সেভ থাকে — পরে সাইট খুললে বা Enter Chat চাপলে কোড ছাড়াই ঢোকে, ব্রাউজার বন্ধ করলেও। আবার কোড চাইবে শুধু: অ্যাডমিন কোড বদলালে, ব্রাউজারের ডেটা মুছলে/incognito/অন্য ডিভাইসে।

---- আপডেট (২০২৬-১০-২৩, ৭): স্ক্রীনশট সুরক্ষা জোরদার ----
* ON/OFF আগের মতোই অ্যাডমিন → মডারেশন → 🛡 স্ক্রীনশট সুরক্ষা (fa_set_shot)। ডিফল্ট বন্ধ।
* চালু থাকলে চ্যাট পুরো কালো হয়: ট্যাব/অ্যাপ বদল, pagehide/freeze, ডেস্কটপে ফোকাস হারানো, PrintScreen/Win+Shift+S/Cmd+Shift+3-4-5/Ctrl+P, ৩-আঙুলের স্পর্শ, ওপর/নিচ কিনার থেকে টান।
* ওয়েব ব্রাউজারে ফোনের পাওয়ার+ভলিউম স্ক্রীনশট ও স্ক্রীন রেকর্ড পুরো আটকানো/ধরা অসম্ভব। পুরো আটকাতে APK + FLAG_SECURE লাগে।


---- আপডেট (২০২৬-১০-২৩, ৮): 📸 স্ক্রীনশট নোটিশ (শুধু অ্যাডমিন দেখে) ----
নতুন SQL: supabase-screenshot-log.sql — একবার Run (আবার চালালেও ক্ষতি নেই; অন্য SQL-এর ক্রমের সাথে সম্পর্ক নেই)।
* কেউ স্ক্রীনশটের চেষ্টা করলে (PrintScreen, Cmd+Shift+3/4/5, Win+Shift+S, ৩-আঙুলের স্পর্শ) সার্ভারে লগ হয়। "🛡 স্ক্রীনশট সুরক্ষা" চালু/বন্ধ যাই থাক, লগ হয়। অ্যাডমিন নিজে নিলে লগ হয় না।
* সাধারণ ইউজার (যে নিল সে-ও) কিছুই দেখে না। পড়ার ফাংশন fa_admin_shots শুধু অ্যাডমিনের; টেবিল সরাসরি পড়া যায় না।
* অ্যাডমিন (একই ব্রাউজারে admin.html-এ লগইন থাকলে) চ্যাটের ভেতরে ঘটনার জায়গায় দেখে: "📸 নাম স্ক্রীনশট নিয়েছে · ৩:৪৫ PM"। সময়ে চাপলে ইউজার ইনফো (নাম, আইডি, বিভাগ, সেশন, আইপি, লোকেশন, ডিভাইস, অনলাইন/Last Active, বার্তা, স্ক্রীনশট কতবার)।
* একই ডিভাইসের পরপর চেষ্টা ৫ সেকেন্ডে একবার গণনা হয়। লগ ৬০ দিন পর নিজে মুছে যায়।
* ⚠ সীমা: ফোনের পাওয়ার+ভলিউম বাটনের স্ক্রীনশট ও স্ক্রীন রেকর্ড ওয়েব ব্রাউজার জানতেই পারে না — তাই তা ধরা যায় না। শুধু কিবোর্ড শর্টকাট ও ৩-আঙুলের স্পর্শ ধরা পড়ে।
* ফাইল বদলেছে: chat.js, index.html (chat.js?v=shot1 — ক্যাশ এড়াতে)। নতুন: supabase-screenshot-log.sql।
